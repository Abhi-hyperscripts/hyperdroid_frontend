Custom Lead Fields

What are custom lead fields?

Custom lead fields are dropdown attributes you can attach to every lead — for example: Potential (Zero / Low / Mid / High), Brochure Sent (Yes / No / NA), Course Interest (whatever your business needs).

Each field you create here shows up automatically in three places:

  • Activity log modal — when a sales rep logs a call/meeting, they pick a value from your dropdown.
  • Leads table filter bar — managers filter the list by any combination of dropdown values.
  • Leads table column — the value renders as a colored badge so you spot Hot leads at a glance.

Field code is permanent once set. label and option colors can be changed any time.

How do I connect my Facebook Lead Ads?

Paste a System User token minted inside your own Meta Business Manager. You stay in control of the permissions, and we never touch your Facebook account directly.

Step-by-step walkthrough with screenshots: Facebook Lead Ads → Ragenaizer CRM Setup Guide  — covers Business Manager, Meta App, the System User token (and the one click order most people get wrong), and form mapping.

Quick reference:

  1. Open business.facebook.com. Create a Business Manager if you don't have one (free, 2 min).
  2. In Business Settings → Accounts → Pages, add the Facebook Page that runs your lead ads.
  3. In Business Settings → Users → System Users, click Add. Name it "CRM Integration", role: Employee.
  4. Assign assets to the System User — click the System User, Add Assets → Pages, pick your page, grant "Access Page" and "Manage Page". This is the step most people miss.
  5. Still on the System User screen, click Generate New Token. In the permissions dropdown, click only leads_retrieval — Meta auto-locks the five required dependencies (business_management, pages_manage_ads, pages_show_list, pages_manage_metadata, pages_read_engagement). Header should read "6 options selected". Set Token Expiration: Never.
  6. Copy the token (Meta only shows it once) and paste it below.

After connecting, pick which pages and forms you want, and map each form's questions to CRM fields — same as a CSV import.

What is Conversion API and why turn it on?

Meta CAPI sends server-to-server conversion events (Lead, QualifiedLead) from this CRM directly to Meta. Once turned on, Meta's ad optimizer learns from your real lead quality, not just form submissions — typically cuts cost-per-qualified-lead by 30–50% over a few weeks.

What you need:

  1. Open Meta Events Manager.
  2. Pick (or create) the Pixel you use for this business. Copy the Pixel ID from Settings.
  3. Same Settings page → Conversion API → Generate Access Token. Copy the token.
  4. Paste both below, click Save & Enable, then Test Connection. You should see events_received: 1.

No browser pixel install required for CAPI — Meta dedups across both if you have both. We send Lead on every new lead and QualifiedLead when a salesperson marks a lead as qualified.

What is this and how do I set it up?

WhatsApp Business messaging via Interakt — Meta's official BSP. Each WhatsApp number you've bought on Interakt gets stored separately so you can run multiple lines (sales, support, etc.).

Add a number in three steps:

What is this and how does it work?

These documents are the AI's only source of truth when it chats with new WhatsApp contacts. It will never invent prices or offers — if the answer isn't in a document, it says it will check with the team and hands off to a human.

Requires an active Anthropic key under Admin → API Keys. Escalations ("talk to a human", ready-to-buy, complaints) ping your admins by push notification.

Calling

Make and receive calls directly from a lead via Exotel, MyOperator, or any future provider you connect. Every call logs to the lead timeline with recording + transcript.

Not connected
How do I connect a calling provider?

You bring your own telephony account — we don't resell minutes. Pick the provider that already serves your business, then follow the matching playbook.

Option A — Exotel (Twilio-compatible, India-focused)

  1. Sign up at my.exotel.com (free trial includes ₹500 credits for 15 days).
  2. Open Settings → API Settings and copy the Account SID, API Key, API Token, plus your ExoPhone (Indian number Exotel assigned — used as caller-ID).
  3. Paste them into Admin → API Keys → Add (Exotel) and Save.
  4. Copy the Status callback URL we generate, then in Exotel: Call Settings → App Bazaar → paste into the call-status-update webhook (POST + application/x-www-form-urlencoded).
  5. Submit Exotel KYC (Company PAN, COI, Address Proof, Photo). Outbound calls work once KYC clears (24–72h).

Option B — MyOperator (IVR-routed, India-focused)

  1. Sign up / log in at app.myoperator.com.
  2. Open APIs & Webhook → Developer API → Calling APIs. Click Generate Credentials and copy the Company ID, the x-api-key, and the Authentication value (click Show value).
  3. Create / pick an IVR under Call → IVR Flows and note its Public IVR ID — outbound calls won't dial without it.
  4. Paste all five (Company ID + x-api-key + Secret Token + Public IVR ID + your DID phone) into Admin → API Keys → Add (MyOperator) and Save.
  5. Copy the webhook URL we generate, then in MyOperator: APIs & Webhook → Webhooks v2 → paste as Target URL (POST + application/json). Subscribe to call.initiated, call.answered, call.end, call.summary, disposition.

Once connected: Call buttons appear on every lead. Inbound calls surface as a toast → click to open the lead. Recordings + transcripts land in the lead timeline.

Automations

Status-change email triggers across every team. Whenever a lead enters a status, the matching template fires automatically.

What is this?

Automations let you wire an email template to a lead status, so the moment a salesperson moves a lead into that status the template is sent — no manual click required.

Triggers are configured per team: each team can have its own greeting, follow-up, or "thank you" sequence. A trigger can also be scoped to a specific lead source (e.g. only send the Facebook welcome email when the lead came from Facebook).

Each (lead, template) pair fires exactly once — re-entering the same status will not double-send. To edit triggers for a team, click Manage below or open Settings → Teams Setup → envelope icon on the team card.

Call coaching playbook

What is this?

The CRM transcribes every call this team makes and the AI scorer grades each call on Discovery, Value, Objection Handling, and Closing. The playbook tells the AI what kind of selling this team is doing so it grades against the right yardstick.

If you leave all fields blank, the AI scores against universal sales fundamentals based purely on what's in the recording — no industry or motion assumptions.

If you fill these in, the AI uses your motion's playbook (cold call vs inbound vs warm vs enterprise) plus your ICP/value-prop/objective to ground its feedback.
