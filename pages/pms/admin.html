Danger Zone

Operates only on your tenant. Other tenants' data is never touched.

Wipe All PMS Data

Permanently deletes:

  • All projects, sub-projects, tasks, task comments, time entries, timesheets
  • All client cache rows, client contacts, project members, tags, activity log
  • All issues, issue comments, watchers, history, and attachments
  • All PMS files stored in Drive for this tenant (issue attachments, inline images — everything under pms/{tenant}/ on S3)

User accounts, HRMS, Drive (non-PMS files), and other services' data are not touched. The local clients cache rebuilds itself from Accounts the next time you open Clients.
